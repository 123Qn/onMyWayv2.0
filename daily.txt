CACH CHAY LAI MOI TRUONG
- Docker Desktop -> cd Backend && npm run db:up   (container onmyway-db, Postgres cong 5433)
- cd Backend && npm run dev                       (API cong 3000)
- cd onMyWay && npx expo start                    (Metro 8081)
- Emulator: emulator -avd Pixel_4 ; adb reverse tcp:8081 tcp:8081
- App goi API qua EXPO_PUBLIC_API_URL trong onMyWay/.env.local = http://192.168.0.12:3000/api
  (doi neu IP may thay doi: ipconfig)
- Gia lap di chuyen: adb emu geo fix <lng> <lat>  (kinh do truoc). Server bo diem > 250 km/h,
  nen chi test quang duong ngan (vai km) hoac di cham.
- Neu chay qua Claude Code: tien trinh nen bi dung sau 2 tieng (emulator, backend, Metro).
  Khi khoi dong lai ma bao "Port 3000/8081 is already in use" -> con tien trinh node cu chay ngam:
    netstat -ano | findstr ":3000 :8081"   roi   Stop-Process -Id <PID> -Force
  sau do chay lai backend va Metro, roi adb reverse tcp:8081 tcp:8081.
